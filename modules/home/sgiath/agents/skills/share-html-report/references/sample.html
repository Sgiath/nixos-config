Purpose

This page exercises every element styled by report.css so the theme can be reviewed at a glance. Real reports inline this stylesheet and write plain semantic HTML — no classes required for the core look. Body copy stays readable at a comfortable measure, while headings, tables, and code take on the mission-control look. An optional <aside> renders as the side panel you see on the right; omit it and <main> takes the full shell.

Links render as signal-red: an internal anchor stays in-tab, while an external source opens in a new tab and carries an outbound marker. Inline code spans, Ctrl+K keys, highlighted findings, retracted claims, and verified corrections each have distinct treatments.
