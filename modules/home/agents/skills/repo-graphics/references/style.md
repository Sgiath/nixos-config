# Style Reference

Palette, layout templates, and copy-paste skeletons for the house SVG style.

## Palette

| Role                  | Value                                                | Notes                                     |
| --------------------- | ---------------------------------------------------- | ----------------------------------------- |
| Card fill             | `#050505`                                            | near-black, NOT pure black                |
| Card border           | `#1c1c1f`                                            | hairline, `stroke-width` default (1)      |
| Ink (line-work, title)| `#e6e6e9`                                            | all monochrome strokes and the title text |
| Muted (subtitles)     | `#606069`                                            | subtitles, in-diagram labels              |
| Faint (corner meta)   | `#3f3f46`                                            | corner metadata text                      |
| Accent (pick ONE)     | `#f7931a` orange / `#4ade80` green / `#e25d52` red   | one node + its label, nothing else        |

Opacity hierarchy for `#e6e6e9` strokes: hero path 0.5–0.7 · secondary /
construction lines 0.2–0.35 · backdrop rings/grids 0.05–0.1 · moving
particles 0.4–0.6.

Font stack everywhere:
`ui-monospace, 'JetBrains Mono', 'Fira Code', monospace`

## Header caption card (820×220)

Text block centered on the left (~x=244), graphic centered on the right
(~x=585). Subtitle x is nudged −4 relative to the title to optically balance
trailing letter-spacing.

```svg
<svg xmlns="http://www.w3.org/2000/svg" width="820" height="220" viewBox="0 0 820 220" role="img" aria-label="NAME — one-line description">
  <desc>Generated by docs/graphics.exs — WHAT IT DRAWS. Do not edit by hand.</desc>
  <defs>
    <clipPath id="card"><rect x="1" y="1" width="818" height="218" rx="11"/></clipPath>
  </defs>
  <rect x="0.5" y="0.5" width="819" height="219" rx="12" fill="#050505" stroke="#1c1c1f"/>
  <g clip-path="url(#card)">
    <!-- computed line-work centered around (585, 110), bleeding off edges -->
  </g>
  <g font-family="ui-monospace, 'JetBrains Mono', 'Fira Code', monospace" text-anchor="middle">
    <text x="244" y="115" font-size="24" font-weight="300" letter-spacing="8" fill="#e6e6e9">NAME</text>
    <text x="240" y="145" font-size="9" letter-spacing="3" fill="#606069">UPPERCASE SUBTITLE</text>
  </g>
</svg>
```

## Instrument variant (820×220)

Graphic centered (~x=410, y=118), no big title; letterspaced 9px corner
captions instead: project top-left (`#9d9da6`, 10px), epoch/metadata top-right,
descriptors bottom-left/right (`#606069`, baselines y=30 and y=200, margins
x=24 / x=796 with `text-anchor="end"` on the right). Optional faint horizon:
`<line x1="24" y1="118" x2="796" y2="118" stroke="#e6e6e9" stroke-opacity="0.05"/>`.

## Content graphics (README body)

Larger standalone cards (e.g. 720×540), same card/ink/accent rules, an
in-card 20px title top-left (y=40) and a 14px `#606069` caption bottom-left
(y = h−22). Embed:

```html
<p align="center">
  <img src="https://raw.githubusercontent.com/OWNER/REPO/BRANCH/path/a.svg" width="49%" alt="what it really shows"/>
  <img src="https://raw.githubusercontent.com/OWNER/REPO/BRANCH/path/b.svg" width="49%" alt="what it really shows"/>
</p>
```

## Animation idioms (SMIL, long periods)

Orbiting node — circle in a `rotate + scale(1, k)` frame turns circular motion
elliptical; `vector-effect="non-scaling-stroke"` keeps strokes undistorted:

```svg
<g transform="rotate(-18) scale(1, 0.38)">
  <circle r="82" stroke-opacity="0.07" vector-effect="non-scaling-stroke"/>
  <g>
    <animateTransform attributeName="transform" type="rotate" from="0" to="360" dur="60s" repeatCount="indefinite"/>
    <path d="M 28.0 -77.1 A 82 82 0 0 1 82 0" stroke-opacity="0.28" stroke-linecap="round" vector-effect="non-scaling-stroke"/>
    <path d="M 82 0 l 0 0.01" stroke-opacity="0.5" stroke-width="3.6" stroke-linecap="round" vector-effect="non-scaling-stroke"/>
  </g>
</g>
```

(the arc is a fading trail; the zero-length round-cap path is the planet dot)

Particle traveling a computed path (define the path once in `<defs>`, `<use>`
it for the visible stroke, reference it with `<mpath>`):

```svg
<defs><path id="curve" d="M ... L ..."/></defs>
<use href="#curve" fill="none" stroke="#e6e6e9" stroke-opacity="0.55" stroke-width="1.2"/>
<circle r="2" fill="#e6e6e9" opacity="0.5">
  <animateMotion dur="30s" repeatCount="indefinite" rotate="none">
    <mpath href="#curve"/>
  </animateMotion>
</circle>
```

Blink (terminal cursor rhythm):

```svg
<animate attributeName="opacity" values="1;1;0;0" keyTimes="0;0.5;0.5;1" dur="1.2s" repeatCount="indefinite"/>
```

## Generator script skeleton (Elixir)

```elixir
defmodule Header do
  @moduledoc false
  # palette as module attributes; plot window as module attributes
  @xmin -2.0
  @x0 500
  @sx 62

  defp fmt(f), do: :erlang.float_to_binary(f / 1, decimals: 2)
  defp px(x), do: @x0 + (x - @xmin) * @sx
  # ... py/1, domain math, path builders ...

  def svg do
    """
    <svg ...>...</svg>
    """
  end
end

File.write!("docs/header.svg", Header.svg())
```

Header comment states the run command (`elixir docs/graphics.exs`) and what it
writes. Watch sigil delimiters: SVG text containing `(...)` breaks `~s(...)` —
use `~s|...|`.

## Pitfalls

- Corner text (top-right metadata) occupies y ≲ 32 for x ≳ 620: keep line-work
  peaks below it or drop corner text entirely (caption variant has none).
- Letterspaced text is wide: ~8.4 px/char at 9px/ls3, ~22 px/char at 24px/ls8.
  Check the caption block ends well before the graphic region (~x=500).
- Standalone SVG tabs in Chromium can tile/repeat content — verify via an
  `<img>`-embedded HTML preview only.
- GitHub light AND dark must both look intentional; the self-contained dark
  card guarantees this — never rely on page background.
