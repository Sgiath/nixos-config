Purpose

This page exercises every element styled by report.css so the theme can be reviewed at a glance. Real reports link this stylesheet and write plain semantic HTML — no classes required for the core look. Body copy stays readable at a comfortable measure, while headings, tables, and code follow the sgiath.dev design language: hairlines on poster black, tracked uppercase captions. An optional <aside> renders as the side rail you see on the right; omit it and <main> takes the full shell.

Links render as signal-red: an internal anchor stays in-tab, while an external source opens in a new tab and carries an outbound marker. Inline code spans, Ctrl+K keys, highlighted findings, retracted claims, and verified corrections each have distinct treatments.

Publish workflow

  1. Draft

    Write docs/YYYY-MM-DD-slug.html linking the shared stylesheet; run the public-content safety gate.

  2. Verify

    Static checks (one title, one h1, no TODOs) plus browser render at desktop width (1280 px).

  3. Upload

    scp to vesta.local:/data/www/sgiath.dev/llm/; never overwrite an existing report silently.

  4. Confirm

    Compare local and remote sha256, then require HTTP 200 with an HTML content type on the public URL.
